# Code of Conduct

## Our pledge

We want Agent Run Monitor to be a friendly, welcoming project for everyone who uses it or helps build it, whatever their background, identity, experience or level of skill.

## What we expect

- Be kind and patient. Assume good intent, and remember that many contributors work in a second language.
- Be constructive. Criticise code and ideas, not people. Explain why, and suggest a better way when you can.
- Respect people's time and privacy. Never ask anyone to share their session files, code or personal details, and never post someone else's.
- Accept that maintainers may decline a change. A "no" to a pull request is not a judgement of you.

## What is not acceptable

- Harassment, insults, threats or personal attacks, in public or in private.
- Discriminatory jokes or language, and unwelcome sexual attention or imagery.
- Publishing anyone's private information (including data from their machine or their agent sessions) without their explicit permission.
- Deliberately disrupting discussions, or encouraging any of the above.

## Scope

This code applies in all project spaces (issues, pull requests, discussions, reviews and any other channel run by the project) and when someone represents the project elsewhere.

## Reporting

If someone's behaviour makes you uncomfortable, or you see something that breaks this code, contact the maintainers privately. Use GitHub's private vulnerability reporting described in [SECURITY.md](SECURITY.md) and start the report with "Code of Conduct" (it reaches only the maintainers), or message a maintainer directly. Reports are kept confidential.

Maintainers will review every report, respond as soon as they can, and take the action they judge fair. That can be a private word, a public note, removal of comments or code, or a temporary or permanent ban from the project. Maintainers who do not follow this code in good faith may be removed from the project.
